LSTM — Long Short-Term Memory

โครงข่ายความจำระยะยาว-สั้น — หน่วยความจำพิเศษ (cell state) ที่ไหลผ่านทุก timestep พร้อม "ประตู" 3 บานคอยควบคุมว่าจะจำ ลืม หรือส่งออกข้อมูลอะไร

🎯 ลองเล่น

ปรับค่า x (input), h_prev, c_prev แล้วดูประตูทั้ง 3 (forget, input, output) คำนวณค่าออกมา — หรือกด "เล่นลำดับ" เพื่อดู LSTM จำ-ลืมค่าไปทีละขั้น

🧠 ทำงานอย่างไร

f = σ(Wf·[hₜ₋₁,xₜ]+bf)  i = σ(Wi·…)  c̃ = tanh(Wc·…)  cₜ = f·cₜ₋₁ + i·c̃  o = σ(Wo·…)  hₜ = o·tanh(cₜ)
  1. Forget gate (f): ตัดสินใจว่า "ความจำเดิม" ส่วนไหนควรลืม (ค่า 0 = ลืม, 1 = จำไว้)
  2. Input gate (i) + candidate (c̃): ตัดสินใจว่าข้อมูลใหม่ x ส่วนไหนควรจำ และสร้างค่าผู้สมัครเข้าระบบความจำ
  3. อัปเดต cell state (c): cₜ = (ความจำเดิมที่ยังเหลือ) + (ข้อมูลใหม่ที่รับเข้ามา)
  4. Output gate (o): ปล่อยความจำส่วนไหนออกมาเป็น output (hidden state hₜ)
  5. ในขณะที่ RNN ทั่วไปมีปัญหา gradient หาย (ลืมอะไรไกล ๆ เร็ว) LSTM ใช้ประตูเหล่านี้ให้ข้อมูลไหลได้ยาวเป็นร้อย ๆ timestep

✅ ข้อดี

  • จำข้อมูลระยะยาวได้ดี (ชื่อของมันเลย!)
  • แก้ปัญหา vanishing gradient ของ RNN ทั่วไป
  • เหมาะกับข้อมูลลำดับ: ข้อความ เสียง ราคาหุ้น

⚠️ ข้อจำกัด

  • ฝึกช้า — ต้องประมวลผลทีละ timestep (ไม่ขนาน)
  • พารามิเตอร์เยอะ ใช้หน่วยความจำสูง
  • Transformer แซงหน้าในงานภาษาแล้ว (แต่ LSTM ยังใช้ในบางงาน)

⚙️ Parameter Tuning

LSTM ต้องปรับทั้งขนาดโมเดลและรูปแบบข้อมูลลำดับ (sequence) — หน้านี้ใช้หน่วยความจำแบบ fixed-weight

Hidden units (ขนาดความจำ)
ค่าแนะนำ: 32 – 256
ขนาดของ cell state / hidden state — ยิ่งมากยิ่งจำรายละเอียดได้
💡 มากเกิน = overfit + ฝึกช้า · เริ่ม 64 แล้วปรับ
Number of layers
ค่าแนะนำ: 1 – 3
จำนวนชั้น LSTM ซ้อนกัน — เรียนรู้ลำดับชั้นของความหมาย
💡 เกิน 3 ชั้นมักไม่ได้ประโยชน์และฝึกยากขึ้น
Sequence length (lookback)
ขึ้นกับข้อมูล — เช่น 60 วันย้อนหลัง
จำนวน timestep ที่ป้อนต่อตัวอย่าง
💡 ยาวเกิน = ข้อมูลเก่าไม่เกี่ยวข้อง + ฝึกช้า · สั้นเกิน = ไม่เห็น pattern
Learning rate
ค่าแนะนำ: 0.001 (Adam)
ขนาดก้าวการอัปเดตน้ำหนัก
💡 LSTM อ่อนไหวต่อ lr — เริ่ม 1e-3 แล้วปรับลง
Dropout
ค่าแนะนำ: 0.2 – 0.5
กัน overfit โดยสุ่มปิดเซลล์ตอนฝึก
💡 ใช้ recurrent_dropout เมื่อ data เยอะ / overfit
Batch size
ค่าแนะนำ: 16 – 128
จำนวนตัวอย่างต่อรอบอัปเดต
💡 ใหญ่ขึ้น = ฝึกเร็วขึ้น แต่ generalization อาจแย่ลง

💼 การใช้งานจริง

  • แปลภาษาและ Speech-to-text (ยุคก่อน Transformer)
  • พยากรณ์อนุกรมเวลา: ราคาหุ้น ยอดขาย สภาพอากาศ
  • สร้างข้อความ / คำทำนายคำถัดไป (text generation)
  • วิดีโอ: จำแนกท่าทางและกิจกรรมในวิดีโอ
