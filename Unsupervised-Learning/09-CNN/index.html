CNN — Convolutional Neural Network

โครงข่ายประสาทเทียมแบบคอนโวลูชัน — ใช้ "เลนส์สแกน" (kernel/filter) เลื่อนทับภาพเพื่อดึงคุณลักษณะ เช่น ขอบ เส้น มุม ทีละชั้น ๆ

🎯 ลองเล่น

คลิกที่กริดซ้ายเพื่อวาดลวดลาย (7×7 พิกเซล) แล้วดู kernel เลื่อนสแกนไปเรื่อย ๆ เกิดเป็น feature map ทางขวา — ลองเปลี่ยน kernel แล้วดูผลต่าง

ขนาด input: 7×7
Kernel: 3×3
Feature map: 5×5
คำนวณ: —
พิกเซลสว่าง (1) พิกเซลมืด (0) พื้นที่ที่ kernel กำลังมอง

🧠 ทำงานอย่างไร

out(i,j) = Σ Σ input(i+a, j+b) × kernel(a,b) + bias   (แล้วตามด้วย ReLU)
  1. Convolution: kernel (เช่น 3×3) เลื่อนทับภาพทีละตำแหน่ง คูณค่าพิกเซลกับน้ำหนักของ kernel แล้วรวมกัน → ได้ค่า 1 จุดใน feature map
  2. Kernel หลายตัว: แต่ละ kernel จับคุณลักษณะต่างกัน (ขอบแนวนอน แนวตั้ง มุม สี) → ได้หลาย channel
  3. Activation (ReLU): ตัดค่าลบออกเพื่อเพิ่ม non-linearity
  4. Pooling: ลดขนาดภาพ (เช่น max pooling 2×2) ให้เหลือเฉพาะค่าที่สำคัญ — ทำให้ทนต่อการเลื่อน/ย่อของวัตถุ
  5. สลับ Convolution → Pooling หลายชั้น ยิ่งลึกยิ่งจับคุณลักษณะซับซ้อน (เส้น → รูปทรง → หน้า → วัตถุ) แล้วต่อด้วย Fully Connected ชั้นสุดท้าย

✅ ข้อดี

  • แม่นยำระดับมนุษย์ในงานภาพ (จำแนกวัตถุ ตรวจจับใบหน้า)
  • ใช้พารามิเตอร์น้อยกว่า MLP มาก (kernel แชร์กันทั่วภาพ)
  • จับตำแหน่งวัตถุได้แม้ขยับ/หมุนเล็กน้อย (translation invariance)

⚠️ ข้อจำกัด

  • ต้องใช้ข้อมูลและ GPU เยอะ
  • เป็นกล่องดำ อธิบายยาก (แม้มีเทคนิค visualize)
  • ภาพบิดเบี้ยวหรือมุมมองแปลก ๆ ยังทำพลาดได้

💼 การใช้งานจริง

  • จำแนกภาพและตรวจจับวัตถุ (YOLO, ResNet, VGG)
  • รถยนต์ไร้คนขับ: ตรวจจับคนเดินถนน ป้ายจราจร
  • วินิจฉัยภาพทางการแพทย์ (X-ray, MRI)
  • ใบหน้าปลดล็อก ฟิลเตอร์ AR แยกภาพ background (deepfake)
