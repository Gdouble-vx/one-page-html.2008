Reinforcement Learning — Q-Learning

การเรียนรู้แบบเสริมแรง — เอเจนต์ (agent) เรียนรู้จากการลองผิดลองถูกในสิ่งแวดล้อม รับ รางวัล (reward) เมื่อทำดี และถูก ลงโทษ เมื่อทำผิด โดยไม่ต้องมีคำตอบสำเร็จรูป

🎯 ลองเล่น

เอเจนต์ต้องเดินจากมุมซ้ายบนไปให้ถึงดาว ⭐ โดยหลบกำแพง — เริ่มต้นเดินมั่ว ๆ (สีส้ม) แล้วค่อย ๆ ฉลาดขึ้น (สีเขียว) ดูค่า Q-value เปลี่ยนไป

🧠 ทำงานอย่างไร

Q(s,a) ← Q(s,a) + α [ r + γ·max Q(s′,a′) − Q(s,a) ]   (Bellman equation)
  1. State (s) & Action (a): ตำแหน่งของเอเจนต์ และการเคลื่อนที่ 4 ทิศทาง
  2. Reward (r): ถึงเป้าหมาย = +10, ชนกำแพง = −1, เดินปกติ = −0.04 (กดดันให้ถึงเป้าไว)
  3. Q-table: ตารางเก็บ "ความคุ้มค่า" ของการทำ action แต่ละอย่างในแต่ละ state — เริ่มต้นเป็น 0 (ไม่รู้อะไร)
  4. Exploration vs Exploitation: ช่วงแรกสุ่มเดินเยอะ (ε สูง) เพื่อสำรวจ พอเรียนรู้ไป ε ลดลง หันมาเลือก action ที่ Q สูงสุด
  5. ทุกก้าว อัปเดต Q ด้วย Bellman equation — ค่าดี ๆ แผ่ย้อนกลับไปยัง state ก่อนหน้าเรื่อย ๆ จนเอเจนต์รู้ทางลัดที่สั้นที่สุด

✅ ข้อดี

  • เรียนรู้ได้โดยไม่ต้องมีข้อมูล label — แค่รางวัล
  • เก่งกว่ามนุษย์ในเกมบางเกม (Go, Chess, Dota 2)
  • ใช้ได้กับระบบที่ต้องตัดสินใจต่อเนื่อง

⚠️ ข้อจำกัด

  • ต้องลองผิดลองถูกมาก — ข้อมูล/เวลา/พลังงานมหาศาล
  • ออกแบบ reward function ยาก (reward hacking)
  • ไม่เสถียร — ใช้ในโลกจริง (เช่น หุ่นยนต์) เสี่ยงอันตราย

💼 การใช้งานจริง

  • AlphaGo / AlphaZero: เอาชนะแชมป์หมากล้อมและหมากรุก
  • หุ่นยนต์เดิน/จับวัตถุ (robotics)
  • ควบคุมรถยนต์ไร้คนขับและระบบจราจร
  • RLHF — วิธีปรับ ChatGPT ให้ตอบตามที่มนุษย์ต้องการ
