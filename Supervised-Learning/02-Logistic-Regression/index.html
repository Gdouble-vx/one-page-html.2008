🧠 ทำงานอย่างไร

แทนที่จะทำนายค่าตรง ๆ Logistic Regression คำนวณ ความน่าจะเป็น ผ่านฟังก์ชัน Sigmoid ซึ่งบีบผลลัพธ์ให้อยู่ในช่วง 0–1 เสมอ

z = w₁x₁ + w₂x₂ + b   ŷ = σ(z) = 1 / (1 + e−z)
  1. คำนวณผลรวมถ่วงน้ำหนัก z จาก features ทั้งหมด (เหมือน Linear Regression)
  2. ส่ง z เข้าฟังก์ชัน Sigmoid → ได้ค่าความน่าจะเป็นระหว่าง 0 ถึง 1
  3. ถ้า ŷ ≥ 0.5 ทำนายเป็น class 1, ถ้า < 0.5 ทำนายเป็น class 0
  4. ฝึกด้วย Binary Cross-Entropy Loss + ปรับน้ำหนักด้วย Gradient Descent

จุดตัดของเส้นแบ่งคือตำแหน่งที่ σ(z) = 0.5 หรือ z = 0 — ด้านหนึ่งของเส้นเป็น class 0 อีกด้านเป็น class 1

✅ ข้อดี

  • ให้ความน่าจะเป็น ไม่ใช่แค่คำตอบ — นำไปใช้ตัดสินใจต่อได้
  • เร็ว ฝึกง่าย เหมาะกับข้อมูลขนาดใหญ่
  • ตีความได้: ค่าสัมประสิทธิ์บอกทิศทางและขนาดของผลต่อ class

⚠️ ข้อจำกัด

  • เส้นแบ่งเป็นเส้นตรง — ไม่เหมาะกับข้อมูลที่ซับซ้อนแบบ non-linear
  • ไวต่อ multicollinearity (ตัวแปรมีความสัมพันธ์กันเองสูง)
  • ถ้าข้อมูลสอง class แยกกันชัดเจนมาก น้ำหนักอาจพองโต (ถ้าไม่มี regularization)

💼 การใช้งานจริง

  • คัดกรองอีเมลสแปม (สแปม / ไม่สแปม)
  • ทำนายว่าลูกค้าจะซื้อสินค้าหรือไม่ (จากพฤติกรรม)
  • วินิจฉัยโรคจากผลตรวจ (เป็นโรค / ไม่เป็น)
  • พยากรณ์โอกาสที่ผู้กู้จะชำระหนี้คืน
