k-Nearest Neighbors (kNN)

เพื่อนบ้านใกล้ที่สุด k ตัว — "บอกฉันว่าเพื่อนบ้านของเธอเป็นใคร แล้วฉันจะบอกว่าเธอเป็นใคร"

← กลับหน้าแรก

🎯 ลองเล่น

คลิกบนกราฟเพื่อวางจุดทดสอบ (ดาวสีขาว) kNN จะหาเพื่อนบ้านที่ใกล้ที่สุด k ตัว แล้วโหวตว่าเป็น class ไหน

ผลทำนาย: —
คะแนนโหวต: —
ระยะถึงเพื่อนบ้านไกลสุด: —
Class A (สีส้ม) Class B (สีน้ำเงิน) Class C (สีม่วง) จุดทดสอบ

🧠 ทำงานอย่างไร

d(p, q) = √[(x₁−x₂)² + (y₁−y₂)²]   (Euclidean distance)
  1. เก็บข้อมูลฝึกทั้งหมดไว้ในหน่วยความจำ (ไม่มีการ "เรียนรู้" จริง ๆ ระหว่างฝึก!)
  2. เมื่อมีข้อมูลใหม่เข้ามา คำนวณระยะทางจากจุดใหม่ไปยังทุกจุดในข้อมูลฝึก
  3. เลือกจุดที่ใกล้ที่สุด k จุด
  4. ให้เพื่อนบ้าน โหวต — class ที่มีเสียงข้างมากมากที่สุดคือคำตอบ

ค่า k มีผลมาก: k เล็ก → ไวต่อ noise (overfit), k ใหญ่ → เรียบเกินไป (underfit) ลองเลื่อน slider แล้วสังเกตผลครับ

✅ ข้อดี

  • ง่ายสุด ๆ ไม่มีสมมติฐานเรื่องรูปร่างข้อมูล
  • ได้ผลดีกับข้อมูลขนาดเล็กและมี label ครบ
  • ใช้ได้ทั้ง classification และ regression

⚠️ ข้อจำกัด

  • ช้าเมื่อข้อมูลใหญ่ (ต้องคำนวณระยะกับทุกจุด)
  • ไวต่อขนาดของ feature — ต้อง normalize เสมอ
  • ปัญหาความหนาแน่นสูง (curse of dimensionality) เมื่อ feature เยอะ

⚙️ Parameter Tuning

kNN มีพารามิเตอร์ไม่กี่ตัว แต่มีผลต่อผลลัพธ์มาก — หน้านี้ลองเลื่อน slider k ได้เลย

k (จำนวนเพื่อนบ้าน)
ค่าแนะนำ: 3 – 15 (ลอง 1 – 20)
จำนวนเพื่อนบ้านที่โหวต — k เล็ก = ไวต่อ noise, k ใหญ่ = เรียบเกิน
💡 ใช้ validation set หรือ Cross-Validation หา k ที่ accuracy สูงสุด
Distance metric
Euclidean / Manhattan / Minkowski
วิธีวัดระยะระหว่างจุด
💡 Manhattan ใช้ได้ดีกับข้อมูลมิติสูง (curse of dimensionality)
Weight function
uniform / distance
'distance' ให้เพื่อนบ้านที่ใกล้มีสิทธิโหวตมากกว่า
💡 ช่วยเมื่อข้อมูลไม่กระจายสม่ำเสมอ
Feature scaling
StandardScaler / MinMaxScaler
ปรับขนาด feature ก่อนคำนวณระยะทางเสมอ
💡 ⚠️ ข้อนี้สำคัญที่สุด — ถ้าไม่ scaling feature ที่หน่วยใหญ่จะชนะการคำนวณระยะทั้งหมด

💼 การใช้งานจริง

  • ระบบแนะนำสินค้า: หา user ที่คล้ายกันแล้วแนะนำสิ่งที่พวกเขาชอบ
  • จดจำลายมือ (เช่น ตัวเลข MNIST) ในยุคแรก ๆ
  • ตรวจจับความผิดปกติ (outlier detection)
  • การพยากรณ์ราคาอสังหาฯ จากบ้านที่คล้ายกันในละแวก
