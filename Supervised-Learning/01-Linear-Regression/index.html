การถดถอยเชิงเส้น — หาเส้นตรงที่อธิบายความสัมพันธ์ระหว่างตัวแปรต้น (x) กับค่าที่ต้องการทำนาย (y)

🎯 ลองเล่น

ลากจุดสีฟ้าบนกราฟเพื่อดูเส้นฟิตเปลี่ยนแบบเรียลไทม์ กดปุ่มเพื่อสุ่มข้อมูลใหม่

💡 คลิกบนกราฟเพื่อเพิ่มจุด แล้วลากจุดเพื่อย้าย
สมการ: y = 0x + 0
ความชัน m = 0
จุดตัด b = 0
R² = 0.000

🧠 ทำงานอย่างไร

Linear Regression หาเส้นตรง y = mx + b ที่ทำให้ผลต่างระหว่างค่าจริงกับค่าที่ทำนาย (error) น้อยที่สุด โดยใช้วิธี Least Squares (กำลังสองน้อยที่สุด)

error = Σ (yᵢ − ŷᵢ)²  โดยที่  ŷᵢ = m·xᵢ + b
  1. สมมติให้ความสัมพันธ์เป็นเส้นตรง: y = mx + b
  2. คำนวณ error ของทุกจุด = ระยะห่างแนวตั้งยกกำลังสอง
  3. ปรับค่า m และ b ให้ error รวมน้อยที่สุด (จุดต่ำสุดของฟังก์ชัน error)
  4. ได้เส้นตรงที่ฟิตข้อมูลได้ดีที่สุด — ใช้ทำนายค่า y ใหม่จากค่า x ใด ๆ

R² (Coefficient of Determination) วัดว่าโมเดลอธิบายความแปรปรวนของข้อมูลได้ดีแค่ไหน — ค่าใกล้ 1 = ฟิตดีมาก, ค่าใกล้ 0 = แทบไม่ดี

✅ ข้อดี

  • เข้าใจง่ายและรวดเร็วในการคำนวณ
  • ผลลัพธ์ตีความได้ (ค่าสัมประสิทธิ์บอกน้ำหนักของแต่ละตัวแปร)
  • เหมาะกับข้อมูลขนาดใหญ่และมีความสัมพันธ์เชิงเส้น

⚠️ ข้อจำกัด

  • สมมติว่าความสัมพันธ์เป็นเส้นตรง — ข้อมูลจริงมักซับซ้อนกว่า
  • ไวต่อค่าผิดปกติ (outlier) มาก
  • มีสมมติฐานเรื่องการกระจายตัวของ error (normality, homoscedasticity)

💼 การใช้งานจริง

  • ทำนายราคาบ้านจากขนาดพื้นที่และทำเล
  • พยากรณ์ยอดขายจากงบโฆษณา
  • ประมาณอายุจากขนาดของสิ่งมีชีวิตในงานชีววิทยา
  • คาดการณ์อุณหภูมิจากตัวแปรสภาพอากาศ
