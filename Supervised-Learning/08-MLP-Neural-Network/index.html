MLP — Multi-Layer Perceptron

โครงข่ายประสาทเทียมแบบหลายชั้น — ต่อเซลล์ประสาท (perceptron) หลายชั้นซ้อนกัน เรียนรู้ฟังก์ชันซับซ้อนอย่าง XOR ที่เส้นตรงทำไม่ได้

🎯 ลองเล่น

MLP กำลังเรียนรู้ปัญหา XOR (จุดสีเดียวกัน = class เดียวกัน) — ดูเส้นแบ่งโค้ง ๆ เกิดขึ้นจาก 4-2-1 โครงข่าย และกราฟ loss ลดลงเรื่อย ๆ

🧠 ทำงานอย่างไร

h = ReLU(W₁x + b₁)   ŷ = σ(W₂h + b₂)
  1. Forward pass: ข้อมูลไหลจาก input layer → hidden layers → output layer โดยแต่ละเซลล์คำนวณ ผลรวมถ่วงน้ำหนัก + activation function
  2. Activation: ReLU, Sigmoid, Tanh — เพิ่มความ "ไม่เป็นเส้นตรง" ให้โครงข่ายเรียนรู้รูปทรงซับซ้อนได้
  3. Loss: เปรียบเทียบคำตอบที่ทำนายกับคำตอบจริง (เช่น Cross-Entropy)
  4. Backpropagation: คำนวณว่าการเปลี่ยนน้ำหนักแต่ละตัวทำให้ loss เพิ่ม/ลดแค่ไหน (gradient) แล้วปรับน้ำหนักให้ loss ลดลง (Gradient Descent)
  5. ทำซ้ำหลายพันรอบจน loss ต่ำ — น้ำหนักที่ได้คือ "ความรู้" ของโมเดล

✅ ข้อดี

  • Universal approximator — เรียนรู้ฟังก์ชันใดก็ได้ถ้ามีชั้นเพียงพอ
  • ใช้กับได้ทุกอย่าง: ตัวเลข, ภาพ, ข้อความ, เสียง
  • เป็นพื้นฐานของ deep learning ทั้งหมด

⚠️ ข้อจำกัด

  • ต้องใช้ข้อมูลจำนวนมากและพลังคำนวณสูง
  • เป็น "กล่องดำ" — อธิบายว่าทำไมถึงตัดสินใจแบบนั้นยาก
  • ต้องปรับ hyperparameter หลายตัว (layer, neuron, learning rate)

⚙️ Parameter Tuning

MLP มีพารามิเตอร์เยอะที่สุด — เริ่มจากโครงสร้างเล็ก ๆ แล้วค่อยเพิ่ม (หน้านี้ใช้ 2 hidden nodes, lr=0.5)

Hidden layers & neurons
ค่าแนะนำ: (64, 32) → (128, 64) ไล่ขึ้น
จำนวนชั้นและเซลล์ต่อชั้น — กำหนดความสามารถในการเรียนรู้
💡 เริ่มเล็กแล้วเพิ่มจน validation error หยุดดีขึ้น — ใหญ่เกิน = overfit
Activation function
ReLU (นิยม) / tanh / sigmoid
ฟังก์ชันไม่เป็นเส้นตรงระหว่างชั้น
💡 ReLU เร็วและแก้ vanishing gradient ได้ดีที่สุดในทางปฏิบัติ
Learning rate
ค่าแนะนำ: 0.0001 – 0.01 (Adam)
ขนาดก้าวการอัปเดตน้ำหนัก
💡 ใหญ่เกิน → loss พุ่ง/แกว่ง · เล็กเกิน → ไม่คืบหน้า
Optimizer
Adam (default) / SGD + momentum
อัลกอริทึมปรับน้ำหนัก

ค่าแนะนำ: 16 – 256
จำนวนตัวอย่างต่อรอบการอัปเดต
💡 เล็ก = อัปเดตบ่อย noisy · ใหญ่ = เรียบ แต่ใช้หน่วยความจำมาก
Dropout / Weight decay
dropout: 0.2 – 0.5 · decay: 1e-5 – 1e-3
เทคนิคลด overfit
