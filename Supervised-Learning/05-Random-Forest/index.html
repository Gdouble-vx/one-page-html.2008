Random Forest

ป่าสุ่ม — ฝึกต้นไม้ตัดสินใจหลายร้อยต้นด้วยข้อมูลสุ่มต่างกัน แล้วให้ทุกต้นโหวต "ภูมิปัญญาของฝูงชน" ทำให้แม่นยำและทนต่อ overfit

🧠 ทำงานอย่างไร

ผลรวม = vote( ต้น₁ + ต้น₂ + ... + ต้นₙ )  ·  Bagging + Random feature selection
  1. Bootstrap sampling: สุ่มหยิบข้อมูลฝึกแบบคืนที่ (sampling with replacement) ให้แต่ละต้นได้ข้อมูลชุดต่างกัน
  2. Random feature: ในแต่ละ split แต่ละต้นเลือกพิจารณาแค่ subset ของ features แบบสุ่ม
  3. ฝึกต้นไม้จำนวนมาก (หลายร้อยต้น) แต่ละต้นไม่สมบูรณ์แบบ — "weak learner"
  4. เวลาทำนาย ให้ทุกต้นโหวต แล้วใช้เสียงข้างมากเป็นคำตอบสุดท้าย

การสุ่ม 2 อย่างนี้ทำให้แต่ละต้น "ผิดคนละแบบ" เมื่อรวมกันแล้ว error ต่าง ๆ หักล้างกัน → โมเดลรวมแม่นกว่าและไม่ overfit

✅ ข้อดี

  • แม่นยำสูง ลด overfit จากต้นไม้เดี่ยวได้มาก
  • รับทั้งตัวเลขและหมวดหมู่ ไม่ต้องปรับขนาดข้อมูล
  • วัดความสำคัญของ feature (feature importance) ได้ฟรี
  • เทรนแบบขนานได้ (แต่ละต้นอิสระต่อกัน)

⚠️ ข้อจำกัด

  • ช้ากว่าและใช้หน่วยความจำมากกว่าต้นไม้เดี่ยว
  • ตีความผลลัพธ์ยากขึ้น (ยังดีกว่า neural network)
  • อาจ overfit ข้อมูลที่มี noise สูงมาก

⚙️ Parameter Tuning

Random Forest ทนทานต่อพารามิเตอร์พอสมควร แต่ปรับตัวนี้แล้วได้ผลดี (หน้านี้ใช้ n_estimators=60)

💡 เลื่อนดู accuracy เพิ่มขึ้นตามจำนวนต้น — สังเกตว่าพอถึงจุดหนึ่งแทบไม่ดีขึ้นแล้ว

n_estimators (จำนวนต้น)
ค่าแนะนำ: 100 – 1000
ยิ่งมากยิ่งแม่นและเสถียร แต่ช้าลง
💡 ผลตอบแทนลดลงเรื่อย ๆ — ดูจุดที่ accuracy หยุดเพิ่มแล้วหยุด
max_depth
ค่าแนะนำ: 10 – 30 หรือ None
ความลึกของแต่ละต้น — จำกัดเพื่อลด overfit
💡 Forest overfit น้อยกว่าต้นไม้เดี่ยว แต่ depth สูงเกินก็ยัง overfit ได้
max_features
ค่าแนะนำ: 'sqrt' (default) / 'log2'
จำนวน feature ที่สุ่มพิจารณาตอนแบ่ง — หัวใจของความหลากหลาย
💡 เล็กลง → ต้นไม้ต่างกันมาก → ensemble แข็งแรงขึ้น
min_samples_leaf
ค่าแนะนำ: 1 – 5
จำนวนข้อมูลขั้นต่ำในโหนดปลาย
💡 เพิ่มนิดเดียวช่วยลด overfit ได้มากโดย accuracy ไม่ตก
bootstrap
True (default) / False
สุ่มหยิบข้อมูลแบบคืนที่ให้แต่ละต้น
💡 False = ใช้ข้อมูลเต็มชุดทุกต้น → ต้นไม้เหมือนกัน → เสียความหลากหลาย

💼 การใช้งานจริง

  • ธนาคาร: คะแนนเครดิตและการตรวจจับการฉ้อโกง
  • แพทย์: ทำนายการเกิดโรคจากข้อมูลสุขภาพ
  • การตลาด: พยากรณ์ลูกค้าที่จะเลิกใช้บริการ
  • Remote sensing: จำแนกประเภทการใช้ที่ดินจากภาพถ่ายดาวเทียม
