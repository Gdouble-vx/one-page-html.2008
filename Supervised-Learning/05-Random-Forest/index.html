🧠 ทำงานอย่างไร

ผลรวม = vote( ต้น₁ + ต้น₂ + ... + ต้นₙ )  ·  Bagging + Random feature selection
  1. Bootstrap sampling: สุ่มหยิบข้อมูลฝึกแบบคืนที่ (sampling with replacement) ให้แต่ละต้นได้ข้อมูลชุดต่างกัน
  2. Random feature: ในแต่ละ split แต่ละต้นเลือกพิจารณาแค่ subset ของ features แบบสุ่ม
  3. ฝึกต้นไม้จำนวนมาก (หลายร้อยต้น) แต่ละต้นไม่สมบูรณ์แบบ — "weak learner"
  4. เวลาทำนาย ให้ทุกต้นโหวต แล้วใช้เสียงข้างมากเป็นคำตอบสุดท้าย

การสุ่ม 2 อย่างนี้ทำให้แต่ละต้น "ผิดคนละแบบ" เมื่อรวมกันแล้ว error ต่าง ๆ หักล้างกัน → โมเดลรวมแม่นกว่าและไม่ overfit

✅ ข้อดี

  • แม่นยำสูง ลด overfit จากต้นไม้เดี่ยวได้มาก
  • รับทั้งตัวเลขและหมวดหมู่ ไม่ต้องปรับขนาดข้อมูล
  • วัดความสำคัญของ feature (feature importance) ได้ฟรี
  • เทรนแบบขนานได้ (แต่ละต้นอิสระต่อกัน)

⚠️ ข้อจำกัด

  • ช้ากว่าและใช้หน่วยความจำมากกว่าต้นไม้เดี่ยว
  • ตีความผลลัพธ์ยากขึ้น (ยังดีกว่า neural network)
  • อาจ overfit ข้อมูลที่มี noise สูงมาก

💼 การใช้งานจริง

  • ธนาคาร: คะแนนเครดิตและการตรวจจับการฉ้อโกง
  • แพทย์: ทำนายการเกิดโรคจากข้อมูลสุขภาพ
  • การตลาด: พยากรณ์ลูกค้าที่จะเลิกใช้บริการ
  • Remote sensing: จำแนกประเภทการใช้ที่ดินจากภาพถ่ายดาวเทียม
