Support Vector Machine (SVM)

เครื่องเวกเตอร์สนับสนุน — หาเส้นแบ่งที่ดีที่สุด โดยให้ระยะห่าง (margin) ระหว่างสอง class กว้างที่สุดเท่าที่จะทำได้

🎯 ลองเล่น

กด "ฝึก SVM" เพื่อหาเส้นแบ่งพร้อมขอบ margin ที่กว้างที่สุด — จุดที่ขีดวงไว้คือ Support Vectors ที่กำหนดตำแหน่งของเส้น

🧠 ทำงานอย่างไร

minimize  ½‖w‖² + C·Σ max(0, 1 − yᵢ(w·xᵢ + b))   (Hinge Loss)
  1. หาเส้นแบ่ง w·x + b = 0 ที่แยกสอง class ออกจากกัน
  2. ไม่ใช่แค่แยกได้ — ต้องแยกให้ margin (ระยะถึงจุดที่ใกล้ที่สุด) กว้างที่สุดด้วย
  3. จุดข้อมูลที่อยู่บนขอบ margin พอดีเรียกว่า Support Vectors — มีแค่จุดเหล่านี้เท่านั้นที่กำหนดเส้นแบ่ง
  4. ถ้าข้อมูลไม่ separable ใช้ค่า C ควบคุมการยอมให้ผิดบ้าง (soft margin)

Kernel trick: ถ้าข้อมูลไม่แยกด้วยเส้นตรง ให้ "ย้าย" ข้อมูลไปมิติที่สูงขึ้น (เช่น RBF kernel) แล้วหาเส้นแบ่งในมิตินั้น — ทำให้ SVM จับรูปทรงโค้งได้โดยไม่ต้องคำนวณมิติสูงจริง ๆ

✅ ข้อดี

  • แม่นยำสูงโดยเฉพาะข้อมูลมิติสูง (เช่น ภาพ)
  • ใช้หน่วยความจำน้อย — จำแค่ support vectors ไม่ใช่ทุกจุด
  • Kernel trick ทำให้จับความสัมพันธ์ซับซ้อนได้

⚠️ ข้อจำกัด

  • ไม่เหมาะกับข้อมูลขนาดใหญ่ (ฝึกช้า)
  • ต้องปรับพารามิเตอร์ (C, kernel, gamma) หลายตัว
  • ผลลัพธ์ตีความยาก และอ่อนไหวต่อการเลือก kernel

⚙️ Parameter Tuning

หัวใจของ SVM คือคู่ (C, kernel, gamma) — ต้องปรับด้วยกัน ใช้ GridSearch เป็นหลัก

C (regularization)
ค่าแนะนำ: 0.1 – 100
C ใหญ่ = ยอมให้ผิดน้อย (margin แคบ) · C เล็ก = ยอมผิดได้ (margin กว้าง)
💡 ข้อมูลมี noise เยอะ → ใช้ C เล็ก ๆ เพื่อกัน overfit
Kernel
linear / rbf / poly / sigmoid
ฟังก์ชันย้ายข้อมูลไปมิติสูง — rbf นิยมที่สุด
💡 เริ่ม linear ก่อน ถ้าแม่นไม่พอค่อยลอง rbf
Gamma (เฉพาะ rbf/poly)
ค่าแนะนำ: 0.001 – 1 (ลอง log scale)
ความกว้างของอิทธิพลของแต่ละจุด — ใหญ่ = โค้งแหลม ฟิตจุดเดียว
💡 gamma ใหญ่เกิน → overfit · เล็กเกิน → underfit (เส้นเกือบตรง)
Degree (เฉพาะ poly)
ค่าแนะนำ: 2 – 4
ดีกรีของพหุนามใน poly kernel
💡 สูงเกินไป → overfit และคำนวณช้า
Class weight
'balanced' เมื่อข้อมูลไม่สมดุล
ชดเชย class ที่มีตัวอย่างน้อย
💡 ใช้กับข้อมูล เช่น เซ็ตการตรวจจับของหายาก

💼 การใช้งานจริง

  • จำแนกใบหน้าและการจดจำลายมือ
  • จำแนกประเภทข้อความและอารมณ์ (sentiment)
  • ตรวจหาเซลล์ผิดปกติในภาพทางการแพทย์
  • จัดหมวดหมู่ยีนในงานชีวสารสนเทศ
