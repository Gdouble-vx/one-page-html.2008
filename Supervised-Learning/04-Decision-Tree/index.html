ต้นไม้ตัดสินใจ — แบ่งข้อมูลด้วยคำถาม "ถ้า...แล้ว..." ซ้ำ ๆ ไปเรื่อย ๆ เหมือนแผนผังการตัดสินใจ

🎯 ลองเล่น

กด "เพิ่มความลึก" เพื่อให้ต้นไม้เรียนรู้การแบ่งข้อมูลทีละชั้น — ดูเส้นแบ่งบนกราฟซ้าย และโครงสร้างต้นไม้ทางขวา

💡 สีฟ้า/สีส้ม = สอง class · เส้นประสีขาว = จุดแบ่ง (split)
ความลึก: 0
จำนวนโหนด: 1
Accuracy (ชุดฝึก): —

🧠 ทำงานอย่างไร

Gini(t) = 1 − Σ pᵢ²  ·  เลือก split ที่ลด Gini Impurity ได้มากที่สุด
  1. ที่แต่ละโหนด ค้นหา feature + ค่า threshold ที่แบ่งข้อมูลออกเป็น 2 กลุ่มได้ "บริสุทธิ์" ที่สุด (Gini ต่ำสุด)
  2. แบ่งข้อมูลตามเงื่อนไข เช่น อายุ < 30 → ไปซ้าย, อย่างอื่น → ไปขวา
  3. ทำซ้ำในแต่ละกลุ่มย่อย (แบบ recursive) จนกว่าจะบริสุทธิ์หรือถึงความลึกที่กำหนด
  4. โหนดปลาย (leaf) คือคำตอบสุดท้าย — class ที่มีเสียงข้างมากในกลุ่มนั้น

✅ ข้อดี

  • มนุษย์อ่านและอธิบายผลลัพธ์ได้ (interpretable)
  • ไม่ต้องปรับขนาดข้อมูล (scaling) มากนัก
  • จับความสัมพันธ์แบบ non-linear ได้

⚠️ ข้อจำกัด

  • ถ้าลึกเกินไป → overfit ได้ง่ายมาก (จำข้อมูลฝึกทั้งชุด)
  • ไม่เสถียร: ข้อมูลเปลี่ยนนิดเดียว ต้นไม้อาจเปลี่ยนทั้งต้น
  • เส้นแบ่งเป็นแนวตั้ง/แนวนอนเท่านั้น (axis-aligned)

💼 การใช้งานจริง

  • ระบบอนุมัติสินเชื่อ: "ถ้ารายได้สูง และอายุงานเกิน 2 ปี → อนุมัติ"
  • วินิจฉัยโรคเบื้องต้นจากอาการ
  • คัดกรองลูกค้าที่จะเลิกใช้บริการ (churn)
  • เป็นองค์ประกอบพื้นฐานของ Random Forest และ XGBoost
