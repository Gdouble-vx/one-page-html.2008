Stacking (Stacked Generalization)

การซ้อนโมเดล — ฝึกโมเดลพื้นฐาน (base models) หลายตัวให้ทำนายก่อน แล้วเอา คำทำนายของทุกตัว ไปเป็น input ให้โมเดลระดับบน (meta-model) เรียนรู้อีกชั้น เพื่อรวมจุดแข็งของแต่ละโมเดล

⚙️ Parameter Tuning

ปรับค่าแล้วดูผลทันที

Stacking tuning ต่างจากโมเดลเดียว — เน้นที่ความหลากหลายของ base models และวิธีสร้าง meta-features

ความหลากหลายของ Base models
ใช้คนละตระกูล: LR + kNN + Tree + SVM
โมเดลที่ "ผิดคนละแบบ" รวมกันแล้วเก่งกว่าโมเดลที่เหมือนกัน
💡 อย่าใช้ XGBoost + LightGBM + CatBoost เป็น base ล้วน ๆ — ผิดแบบเดียวกัน
Meta-model
Logistic Regression (นิยม) / LightGBM
โมเดลชั้นบนที่เรียนจากคำทำนายของ base models
💡 LR เรียบง่ายและกัน overfit — meta-model ซับซ้อนเกินไปไม่จำเป็น
CV folds (สร้าง meta-features)
ค่าแนะนำ: 5 – 10 (KFold)
จำนวนพับ cross-validation ตอนสร้างคำทำนายบนชุดฝึก
💡 ต้องทำเสมอ ไม่งั้น meta-model เรียนรู้ว่า base "จำข้อมูลฝึกได้" (data leakage)
Output type ของ base models
ใช้ predicted probability ไม่ใช่ label ตรง ๆ
ความน่าจะเป็นมีข้อมูลมากกว่า (บอกความมั่นใจด้วย)
💡 ใช้ proba + class ต่อท้ายเป็น feature เพิ่มก็ได้
Hyperparameter ของแต่ละ base
tuning ปกติของแต่ละโมเดล
แต่ละ base ควรถูก tuned ให้ดีพอสมควรก่อนรวม
💡 ไม่ต้อง perfect — base ที่ overfit เล็กน้อยก็ยังใช้ได้ ถ้าคนละแบบ

🧠 ทำงานอย่างไร

ขั้นที่ 1: p₁, p₂, p₃ = base₁(x), base₂(x), base₃(x)  ·  ขั้นที่ 2: ŷ = meta(p₁, p₂, p₃)
  1. Level-0 (Base models): ฝึกโมเดลหลายแบบ เช่น Logistic Regression, kNN, Decision Tree บนข้อมูลเดียวกัน
  2. ให้แต่ละโมเดลทำนายบนข้อมูลฝึก → สร้างชุดข้อมูลใหม่จากคำทำนายเหล่านี้ (เรียกว่า meta-features)
  3. Level-1 (Meta-model): ฝึกโมเดลอีกตัว (เช่น Logistic Regression) บน meta-features เพื่อเรียนรู้ว่า "โมเดลไหนเก่งตรงไหน ควรเชื่อใครมากน้อยแค่ไหน"
  4. เวลาทำนายข้อมูลใหม่: ให้ base models ทำนายก่อน → ส่งคำทำนายเข้าสู่ meta-model → ได้คำตอบสุดท้าย

⚠️ ควรทำ cross-validation ตอนสร้าง meta-features เพื่อไม่ให้ meta-model เรียนรู้ว่า base models "จำข้อมูลฝึกได้" แทนที่จะเก่งจริง

✅ ข้อดี

  • แม่นยำสูงกว่าการใช้โมเดลเดียวหรือ voting ทั่วไป
  • ใช้จุดแข็งของโมเดลหลายประเภทพร้อมกัน
  • ชนะการแข่งขัน ML หลายรายการ (เช่น Netflix Prize)

⚠️ ข้อจำกัด

  • ช้าและใช้ทรัพยากรหลายเท่า (ต้องฝึกหลายโมเดล)
  • เสี่ยงต่อ data leakage ถ้าไม่ทำ cross-validation
  • ซับซ้อน ดีบักและอธิบายยาก

💼 การใช้งานจริง

  • ชนะการแข่งขัน Kaggle — รวม XGBoost + LightGBM + Neural Network
  • ระบบแนะนำภาพยนตร์ (Netflix Prize)
  • การตรวจจับการฉ้อโกง: รวมโมเดลความเร็วสูงหลายตัว
  • พยากรณ์สภาพอากาศจากหลายแหล่งข้อมูล
